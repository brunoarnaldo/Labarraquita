## Reglas que funcionan

- Prompt en inglés, textos de la imagen en español entre comillas.
- Formato 4:5 para el feed y 9:16 para historias y Reels.
- Pedir la bolsa "inspired by the reference image, recognizable but not an exact copy".
- Dejar libre la esquina superior izquierda para el logo y agregarlo en Canva.
- Cerrar el prompt con "all Spanish text spelled exactly as written".
